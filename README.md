# Engineering Portfolio — Akagra Gangwar

Modern, recruiter-optimized personal developer portfolio deployed at [akagra.dev](https://akagra.dev).

Built for technical recruitment targeting **Software Development Engineer (SDE) Intern**, **Backend Developer Intern**, and **Graduate Engineer Trainee** roles.

---

## 🏛️ Architecture & Technologies

- **Frontend Core:** Semantic HTML5, Vanilla JavaScript (ES6+), Modern CSS3 (CSS Variables, Flexbox, CSS Grid).
- **Styling Architecture:** Custom dark futuristic design system with purple and cyan accents, inspired by modern terminal interfaces.
- **Visuals & Interactivity:** 2D interactive particle canvas, 3D rotating mathematical wireframe globe, 3D card tilt physics, accessible project modals, and keyboard focus trap.
- **Zero Heavy Framework Overheads:** Pure native web technologies without React/Next.js bundle bloat, ensuring sub-second first-contentful paint (FCP) and 100% lighthouse performance.

---

## 📁 Repository Structure

```
├── index.html          # Hero section, flagship showcase, telemetry stats & background
├── projects.html       # Engineering catalog (8 projects), category filters, detail modals & journey
├── skills.html         # Technical capabilities (Languages, Frontend, Backend, Core CS, AI/ML, SWE, Tools)
├── credentials.html    # 10 verified certifications & hackathon achievements
├── about.html          # Professional biography, academic background & online profiles
├── resume.pdf          # Verified ATS-optimized PDF resume
├── style.css           # Global typography, colors, navigation, buttons, and hero layout
├── pages.css           # Page-specific styling for projects, skills, credentials, and about
├── script.js           # Interactive logic (particles, typewriter, filters, modals, globe, focus trap)
└── vercel.json         # Vercel deployment configuration, security headers, and MIME mappings
```

## 🚀 Deployment (Vercel)

This project is pre-configured for automated zero-configuration deployment via Vercel:

1. Push changes to your GitHub repository:
   ```bash
   git add .
   git commit -m "feat: add neural networks, ML regression & hackathon credentials"
   git push origin main
   ```
2. Vercel automatically detects static HTML/CSS/JS and deploys to production with automatic SSL and global edge CDN caching.
